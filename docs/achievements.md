# 成就

当玩家达成特定目标时，会获得成就，并且可选地提供一些奖励。

你可以通过将成就放置在侧边层（side layer）中来创建全局成就，只需将其行（row）设置为 `"side"` 而不是数字即可。

处理成就及其效果的有用函数：

- hasAchievement(layer, id)：判断玩家是否拥有该成就。
- achievementEffect(layer, id)：返回成就的当前效果（如果有）。

成就的格式应如下所示：

```js
achievements: {
    11: {
        name: "Blah",
        more features
    },
    etc
}
```

通常，每个成就的 id 中，第一位数字代表行，第二位数字代表列。

单个成就可以包含以下特性：

- name：**可选**。显示在成就顶部的名称，也是唯一可见的文本。也可以是返回更新文本的函数。可使用基本 HTML。

- done()：返回布尔值的函数，用于判断是否应授予该成就。

- tooltip：成就的默认提示，悬停时显示。应传达目标以及完成成就的任何奖励。也可以是返回更新文本的函数。可使用基本 HTML。设置为 `""` 可禁用提示。

- effect()：**可选**。计算并返回成就带来的任何奖励当前值的函数。可以返回一个值或包含多个值的对象。

- unlocked()：**可选**。返回布尔值的函数，用于判断成就是否可见。默认为已解锁。

- onComplete() - **可选**。此函数将在成就完成时被调用。

- image：**可选**，将给定 URL（相对或绝对）的图片放入成就中。

- style：**可选**。以对象形式向此成就应用 CSS，其中键为 CSS 属性，值为这些属性的值（均为字符串）。

- textStyle：**可选**。以对象形式向文本应用 CSS，其中键为 CSS 属性，值为这些属性的值（均为字符串）。

- layer：**自动分配**。其值与此层的名称相同，因此你可以执行 `player[this.layer].points` 或类似操作。

- id：**自动分配**。它是成就存储时使用的“键”，便于访问。示例中成就的 id 为 11。

- goalTooltip：**可选，已弃用**。当成就被悬停且未完成时显示，覆盖基本提示。用于显示目标（或提示）。也可以是返回更新文本的函数。可使用基本 HTML。

- doneTooltip：**可选，已弃用**。当成就被悬停且已完成时显示，覆盖基本提示。可显示玩家达成的目标以及奖励（如果有）。也可以是返回更新文本的函数。可使用基本 HTML。

通过在层中添加 `achievementsPopups: false` 来禁用成就弹窗。
